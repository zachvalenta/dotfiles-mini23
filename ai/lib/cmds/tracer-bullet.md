## principles

Strong relationship to Thomas' 'Pragmatic Programmer' concept of [tracer bullets](https://en.wikipedia.org/wiki/The_Pragmatic_Programmer) in so far as we're going for *the simplest possible thing* that is also *connected end-to-end*:

> For that initial build, all we could do was submit a query that listed all the rows in a table, but it proved that the UI could talk to the libraries, the libraries could serialize and unserialize a query, and the server could generate SQL from the result. [49]

> A complex system that works is invariably found to have evolved from a simple system that worked. https://news.ycombinator.com/item?id=42668065
